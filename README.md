# flowly

Persistencia local: para que boards y tasks no desaparezcan al cerrar la app. Para mí esta es la próxima más importante.

Editar y eliminar tasks: tocar una task → poder editar título, descripción, fecha, prioridad, board o eliminarla.

Editar/eliminar boards: aunque sea desde un menú de ....

Search: una lupa en Home para buscar tasks por nombre. Es simple y suma bastante.

Notificaciones/reminders: más adelante, que una task con fecha pueda avisarte. Esta ya es más avanzada y la dejaría para el final.

Estados vacíos lindos: cuando no hay boards, tasks o tareas en el calendario, mostrar algo mejor que simplemente espacio vacío.
